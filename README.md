# Router · GLM5.3 Flash 1103

本分支提供PD负载分配、缓存感知路由、P→D分词结果复用、usage统计和长期运行的内存清理。下面按提交说明问题、做法和通用复用范围；一个提交的多项功能放在同一张表内。部署、构建和开关统一见 [DEPLOYMENT.md](DEPLOYMENT.md)。

| 功能 | 遇到的问题 | 做了什么、作用是什么 | 通用复用范围与生效方式 |

| ③ P / D usage合并 | PD传过来的KV不能全部算作历史缓存命中，输出和思考统计也不能丢。 | 使用P实际缓存命中，合并D输出并保留细分usage。 | **通用统计修复**；需要后端提供有效usage。 |
| ④ 健康与负载刷新 | worker状态变化后，Router需要及时更新可选目标。 | 同步健康和负载刷新，匹配分离部署。 | **通用路由能力**；沿用原生检查配置。 |
| ⑤ 固定依赖 | 源码相同但依赖不同，难以复现二进制。 | 固定Cargo依赖及构建凭据。 | **通用工程能力**。 |

## 5. P→D分词结果复用 · 移植自 `08d71951`

| 功能 | 遇到的问题 | 做了什么、作用是什么 | 通用复用范围与生效方式 |
| --- | --- | --- | --- |
| ① D复用P的分词结果 | 长多轮请求在P已经完成分词，D再渲染模板、分词一次，会增加CPU开销和首字等待。 | P返回`prompt_token_ids`，Router将其放入D的KV传输元数据，D通过原生接口直接使用。 | **通用vLLM PD优化**；`/v1/chat/completions`默认开启，`VLLM_ROUTER_PD_REUSE_PROMPT_IDS=0`关闭，精确`1`开启。P/D须使用一致的模型、Tokenizer和模板。 |
| ② 交接校验与参数保留 | 错误的token ID或丢失的KV元数据，会让D接到不完整请求。 | 校验非空、非负u32 token ID；保留原KV元数据和客户端D输出参数，交接不完整时在派发D前报错。 | **通用请求正确性保护**；随复用路径生效。 |
| ③ 复用交接观测 | 需要确认Router是否已经把P的分词结果交给D。 | 增加`vllm_router_pd_prompt_ids_reused_total`交接计数。 | **通用观测能力**；计数表示Router已准备交接，D实际复用及耗时看后端。 |

复用路径等P返回分词结果后再派发D，推理引擎仍使用原生异步调度。HTTP、SSE、DP rank传递和后端usage统计继续沿用原路径。完整4P4D引擎与缓存启动命令见vLLM同名1103分支的`deployment4p4d.md`。

## 6. 长期运行的内存清理

| 位置 | 原来的问题 | 修复后的行为 |
| --- | --- | --- |
| 缓存感知树 | 父子节点互相持有强引用，整棵树被替换后仍占着请求文本；并发拆分与淘汰的锁顺序可能让清理卡住。 | 父指针改成弱引用，释放时逐层拆除；插入/查询与破坏性清理隔离，保留并发查询和插入。 |
| 淘汰线程和旧服务 | 策略移除后，后台线程继续持有缓存；最后一个worker删除后留下空模型树。 | 策略退出时唤醒并回收线程；删除最后一个worker时同步删除模型树。运行中的LRU淘汰继续保留。 |
| 可选耦合实例监测 | 已删除服务的指标轮询一直运行，旧DP记录继续留在内存中。 | 服务移除时停止对应轮询、删除指标快照；策略退出时回收全部轮询。 |
| 动态注册与删除 | 同URL重复注册会重复追加索引；模型变化后旧索引仍持有worker，删除PD基础地址也可能留下各rank。 | 同URL更新只保留一份索引，替换时释放旧模型/角色记录；删除基础地址时清理其全部rank及路由策略。 |
| 可选P KV监测 | 过期观测虽然不参与选路，记录仍留在map里。 | 每轮观测和选路时回收超过5秒的旧记录，保持原有5秒有效期。 |
| API key校验缓存 | 每个新key的校验结果永久保存，随机无效key也会不断累积。 | 最多4096条、单key最多缓存8192字节；成功结果保留300秒，明确拒绝保留30秒。访问时清理过期项，满额淘汰最早过期项；网络错误和上游服务异常不写负缓存。 |

这些修复清理Router自身的对象和后台任务，保留现有PD选路、P→D分词复用及usage统计。引擎GPU KV和MooncakeStore缓存仍由各自的服务管理。

## P/D HTTP 连接池隔离（可选）

设置 `VLLM_ROUTER_PD_DISABLE_HTTP_POOL=1`，仅关闭内部 P/D HTTP 客户端的连接池；
未设置或为 `0` 时保持原配置。用于验证长 SSE 响应下连接误复用的规避方案，
不是 KV/分词缓存开关，不改变流式背压、阶段超时、采样或 POST 不重试策略。
正式压测前应验证对应请求速率下的新建连接、TIME_WAIT 和端口余量。
